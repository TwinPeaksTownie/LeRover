# FEETECH STS3512 / STS3215 Smart Bus Servo Specifications & Protocol Reference

## 1. Technical Overview

The FEETECH STS3512 / STS3215 are high-precision TTL magnetic-encoder smart bus servos operating on a 1 Mbps half-duplex UART bus.

- **Encoder Resolution**: 12-bit absolute magnetic encoder (4096 steps / 360°, 0.0878° per tick).
- **Communication Protocol**: Asynchronous TTL Serial (8-N-1 format, default baud rate 1,000,000 bps).
- **Operating Voltage**: 9.0V – 12.0V DC (Nominal 12.0V).
- **Control Modes**:
  - `Mode 0`: Position Control Mode (0 – 4095 single-turn absolute position).
  - `Mode 1`: Speed Control / Continuous Rotation Mode.
  - `Mode 2`: Step Mode.
  - `Mode 3`: Multi-Turn Position Control Mode.

## 2. FEETECH Serial Packet Protocol Structure

All instruction and status packets follow standard 0xFF 0xFF header framing:

### Instruction Packet (Host -> Servo)
```
[0xFF] [0xFF] [ID] [Length] [Instruction] [Parameters...] [Checksum]
```
- `Header`: `0xFF 0xFF`
- `ID`: Servo ID (1 to 253, Broadcast = `0xFE`).
- `Length`: Number of parameters + 2 (`Instruction` + `Checksum`).
- `Instruction`:
  - `0x01` (PING): Query online status.
  - `0x02` (READ): Read register byte(s).
  - `0x03` (WRITE): Write register byte(s).
  - `0x04` (REG WRITE): Asynchronous write buffer.
  - `0x05` (ACTION): Trigger buffered REG WRITE commands.
  - `0x06` (RESET): Factory reset.
  - `0x83` (SYNC WRITE): Simultaneous multi-servo position target updates.
- `Checksum`: `(~(ID + Length + Instruction + Param1 + ... + ParamN)) & 0xFF`

## 3. Standard Control Registers

| Address | Byte(s) | Parameter Name | Description & Usage |
| :---: | :---: | :--- | :--- |
| `0x05` | 1 | `ID` | Bus Servo ID (1–253). |
| `0x06` | 1 | `Baud Rate` | `0` = 1M bps, `1` = 500k bps, `2` = 250k bps, `3` = 128k bps, `4` = 115.2k bps. |
| `0x21` | 1 | `Mode` | `0` = Position Mode, `1` = Speed Mode, `3` = Multi-Turn Mode. |
| `0x28` | 1 | `Torque Enable` | `0` = Torque Off (limp mode), `1` = Torque Enabled. |
| `0x2A` | 2 | `Goal Position` | Target tick position (`0` – `4095` low-byte first). |
| `0x2E` | 2 | `Goal Speed` | Movement speed limit ticks/sec. |
| `0x30` | 2 | `Goal Torque / Current` | Maximum output torque limit (0 – 1000). |
| `0x38` | 2 | `Present Position` | Live 12-bit encoder tick position (`0` – `4095`). |
| `0x3C` | 2 | `Present Speed` | Live rotation velocity. |
| `0x3E` | 2 | `Present Load` | Output current / load representation. |
| `0x41` | 1 | `Present Temperature` | Internal motor board temperature (°C). |

## 4. Range-Normalized Teleoperation & Home Calculation

- **Default Center**: `2048` ticks ($180^\circ$ physical position).
- **Homing Offset**:
  $$\text{homing\_offset} = \begin{cases} 2048 - \text{raw\_home} & \text{if } \text{drive\_mode} = 0 \\ \text{raw\_home} - 2048 & \text{if } \text{drive\_mode} = 1 \end{cases}$$
- **Safe Working Range**: Bounds are stored in calibration JSON as `range_min` and `range_max` to prevent mechanical binding.
